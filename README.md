# PrimeMath 🎯

Página web moderna para clases de matemática online, dirigida a estudiantes de toda Latinoamérica — desde apoyo escolar secundario hasta preparación para el ingreso universitario.

🔗 **Sitio en vivo:** [v0-primemath-website-design.vercel.app](https://v0-primemath-website-design.vercel.app/)

![Vista previa de PrimeMath](./assets/homepage-preview.png)

## ✨ Qué incluye el sitio

- **Hero con propuesta de valor:** "Domina las Matemáticas a tu Propio Ritmo", con prueba social (98% de aprobación, +500 estudiantes) y CTA directo a WhatsApp.
- **Servicios:** apoyo escolar secundario, preparación universitaria, ingreso a colegios/facultades, exámenes y tutorías especiales.
- **Beneficios:** clases 100% online, profesores expertos, horarios flexibles, adaptado al currículo de cada país.
- **Testimonios** de estudiantes de Colombia, Chile y Argentina con resultados concretos.
- **Planes y precios** en tres niveles (Refuerzo Escolar, Intensivo Universitario, Clases Individuales), con precios adaptados a la moneda local.
- **Métodos de pago:** PayPal, Western Union, tarjetas y transferencia bancaria local.
- **Preguntas frecuentes** y **formulario de contacto** con derivación directa a WhatsApp.

## 🛠️ Stack técnico

- **Framework:** [Next.js](https://nextjs.org/) + React
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Componentes UI:** [Radix UI](https://www.radix-ui.com/) (accordion, dialog, select, tabs, tooltip, etc.)
- **Formularios:** React Hook Form + [Formspree](https://formspree.io/)
- **Despliegue:** [Vercel](https://vercel.com/)
- Generado inicialmente con [v0](https://v0.dev/), el generador de sitios de Vercel.

## 🚀 Cómo correrlo localmente

```bash
pnpm install
pnpm dev
```

Abrí [http://localhost:3000](http://localhost:3000) para verlo en tu navegador.
